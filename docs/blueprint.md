# **App Name**: Muawin

## Core Features:

- User Authentication: Secure user authentication using Firebase Auth with email/password and phone OTP.
- Provider Verification: Admin panel for verifying providers using uploaded CNIC and selfie.
- Job Request and Matching: Matching customer job requests with available providers based on category, location, and rating.
- Real-time Notifications: Push notifications via FCM for job updates, verification status, and complaint resolutions.
- Reviews and Ratings: System for customers to rate and review providers after job completion.
- AI Assistant Chat: Gemini API powered assistant that uses tool based decision making, helping users find services and resolve issues.
- Location Services: Location detection and service radius setting using google_maps_flutter and geolocator.

## Style Guidelines:

- Primary color: Pastel Green (#A8D5A2) for a calming and trustworthy feel.
- Background color: Light off-white (#F7FBF7) for a clean, modern look.
- Accent color: Light Mint (#D4EDDA), for subtle highlights.
- Headline font: 'Poppins', sans-serif, for a modern, clean look.
- Body font: 'Inter', sans-serif, for a readable and neutral feel.
- Material Symbols Rounded for consistent and recognizable icons.
- Smooth transitions and loading animations to improve user experience.
